# Atividade - 1 | Avaliação de Desempenho

## Requisitos do sistema:
- Java - 21
- Apache Maven - 3.9.11
- Docker - 27.5.1

### Para iniciar o ambiente basta digitar o seguinte comando:

- Ambiente Windows
```
.\up_win.bat
```

- Ambiente Linux
```
.\up_linux.sh
```

Ao rodar o script 4 terminais irão aparecer com as informações de cada API.
